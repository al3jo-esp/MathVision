Acerca de MathVision

Una herramienta de reconocimiento de cifras manuscritas mediante inteligencia artificial.

¿Qué es MathVision?

MathVision es una aplicación capaz de reconocer cifras escritas a mano. El usuario puede cargar una fotografía o imagen de un número y la aplicación utiliza una red neuronal para clasificarlo como una de las diez cifras, del 0 al 9.

El objetivo principal es mostrar de forma práctica cómo se puede entrenar y utilizar una red neuronal para resolver una tarea concreta de reconocimiento de imágenes.

¿Cómo se ha creado?

El modelo de inteligencia artificial se ha desarrollado en Python utilizando PyTorch. Para entrenarlo se ha utilizado el conjunto de datos MNIST, formado por imágenes de cifras manuscritas en escala de grises.

La arquitectura elegida es una red neuronal convolucional (CNN). Sus capas convolucionales aprenden patrones visuales —como bordes y formas— y sus capas finales utilizan esos patrones para decidir qué cifra aparece en la imagen.

Después del entrenamiento inicial, el modelo se ha ajustado también con ejemplos de escritura manuscrita propios para adaptarlo mejor a otros estilos de escritura.

¿Cómo funciona el reconocimiento?

  1. El usuario selecciona una imagen que contiene una cifra.
  2. El backend prepara la imagen: la convierte a escala de grises, localiza la cifra y adapta su tamaño al formato que espera la red neuronal.
  3. La CNN analiza la imagen y calcula las probabilidades para las diez clases posibles.
  4. MathVision muestra la cifra que obtiene la puntuación más alta, su nivel de confianza y otras posibilidades.

La tecnología detrás

  • Python y PyTorch: desarrollo, entrenamiento y ejecución del modelo.
  • MNIST: conjunto de datos utilizado como base para el entrenamiento.
  • FastAPI: backend que recibe las imágenes y devuelve las predicciones.
  • HTML, CSS y JavaScript: interfaz web desde la que se utiliza la aplicación.
  • Supabase: gestión de cuentas y sincronización de historial y preferencias entre dispositivos.

Alcance y limitaciones

La función principal actual de MathVision es reconocer una cifra manuscrita cada vez. No está diseñada para interpretar operaciones, ecuaciones completas ni páginas con varios ejercicios. La confianza que muestra el modelo es una estimación de sus probabilidades, no una garantía de que la predicción sea correcta.
